# Risky Bit 
> Diploma 2026/27

This project was made as the practicle part of the teams diploma.


## Description
RiskyBit is a software collection in docker, that aims to provide a enviourment to conduct hacking challenges for companies and schools. Featuring real systems, actual CVEs in a competitive enviourment.

## Installation
This main repository features script to automatically setup up the project for you, run it and after you're done remove it again.

<br>

Fetch the Repository
```Bash 
git clone https://github.com/DA-Risky-Bit/RiskyBit.git 
``` 

Run the script for setup
```Bash 
./riskybit.sh setup  
``` 
Fill Admin-Email, -Password and Postrgess-Password

<br>
Start the compose

```Bash 
./riskybit.sh run  
``` 

> [!NOTE]
> We recommend using this tool, since it automatically saves and loads passwords into the env, so your passwords won't ever lay around in plain text.
